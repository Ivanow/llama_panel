# 🦙 LlamaPanel (LLM Server Manager)

**[English version (README_EN.md)](README_EN.md)**

**Автор:** Kayro | **Репозиторий:** https://github.com/Ivanow/llama_panel

Веб-панель для управления локальными LLM-серверами на базе `llama.cpp`. Позволяет запускать, останавливать и редактировать конфигурации моделей через современный веб-интерфейс. Включает проверку ресурсов (VRAM/RAM), проверку портов и конструктор аргументов.

![LlamaPanel Screenshot](doc/images/llama_panel.jpg)

## 📦 Установка (Linux)

Проект рассчитан на Ubuntu/Debian-подобные системы. Вам понадобятся права `sudo` для установки системных пакетов.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Ivanow/llama_panel.git
   cd llama_panel
   ```

2. **Сделайте скрипт установки исполняемым:**
   ```bash
   chmod +x install.sh
   ```

3. **Запустите установку:**
   Скрипт автоматически проверит и установит недостающие системные пакеты (`cmake`, `tmux`, `curl` и др.), создаст изолированное окружение Python (`venv`), скачает исходники `llama.cpp` и скомпилирует их под ваше железо.
   *(Если у вас мало оперативной памяти, скрипт автоматически снизит количество потоков сборки, чтобы избежать падения).*
   ```bash
   ./install.sh
   ```

4. **Запустите панель:**
   После успешной установки просто выполните:
   ```bash
   ./run.sh
   ```

5. **Откройте панель:**
   Перейдите по адресу `http://<IP_ВАШЕГО_СЕРВЕРА>:8090`.
