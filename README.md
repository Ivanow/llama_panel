# 🦙 LlamaPanel (LLM Server Manager)

**Автор:** Kayro
**Репозиторий:** https://github.com/Ivanow/llama_panel

Веб-панель для удобного управления локальными LLM-серверами на базе `llama.cpp`. Позволяет запускать, останавливать и редактировать конфигурации моделей через современный веб-интерфейс, минуя ручное прописывание аргументов в терминале.

## 🚀 Основные возможности
- **Управление жизненным циклом**: Запуск, остановка и перезапуск серверов в один клик (через `tmux`).
- **Умная проверка ресурсов**: Панель автоматически опрашивает `nvidia-smi` и системную память (RAM). Если модель не влезает в свободную VRAM или RAM, карточка блокируется.
- **Проверка портов**: Защита от запуска двух серверов на одном порту.
- **Визуальный конструктор аргументов**: Удобный выбор параметров (`--n-gpu-layers`, `--ctx-size`, Flash Attention, Draft, Vision и т.д.) с автоматической сборкой строки.
- **Встроенный проводник**: Выбор `.gguf` файлов прямо из веб-интерфейса без копирования путей.

## 🛠 Стек технологий
- **Бэкенд**: Python 3, Flask
- **Фронтенд**: Vanilla JS, CSS Grid / Glassmorphism
- **Управление процессами**: Bash, tmux
- **Движок**: llama.cpp

## 📦 Установка и запуск
1. Убедитесь, что `llama-server` собран и лежит по пути `/stor001/llama_server/build/bin/llama-server`.
2. Установите Flask: `sudo apt install python3-flask`.
3. Запустите бэкенд: `python3 /stor001/llama_server/web_panel/app.py`.
4. Откройте в браузере: `http://<IP_СЕРВЕРА>:8090`.
