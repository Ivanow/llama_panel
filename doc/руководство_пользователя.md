# 📖 Руководство пользователя LlamaPanel

## 1. Главный экран
На главном экране отображаются карточки всех созданных конфигураций. Каждая карточка содержит:
- **Имя конфига** и **Порт**.
- **Статус**: 
  - 🟢 `RUNNING` — сервер работает (модель в памяти).
  - 🟡 `LOADING` — модель загружается в память.
  - 🔴 `STOPPED` — сервер выключен.
- **Кнопки управления**: «Старт», «Стоп», «Рестарт».
- **Карандаш** (✏️) — редактирование конфига.
- **Корзина** (🗑️) — удаление конфига (доступно только для выключенных).

### ⚠️ Серые карточки (Защита от дурака)
Если карточка стала серой, значит, запуск заблокирован. Причина пишется прямо под названием модели:
- **«Недостаточно VRAM»**: Вы попытались запустить модель, когда видеопамять уже занята другими запущенными серверами. Остановите лишнее.
- **«Недостаточно RAM»**: Аналогично для оперативной памяти (актуально для CPU-инференса).
- **«Порт занят другим сервером»**: Вы пытаетесь запустить конфиг на порту, который уже слушает другой работающий сервер.
- **«Файл модели не найден»**: Модель удалена с диска или путь неверен.

## 2. Создание нового сервера
1. Нажмите **«Добавить сервер»**.
2. Введите **Имя конфига** (только латиница, цифры, тире).
3. Укажите **Порт** (по умолчанию 8081).
4. Нажмите **«Обзор»** и выберите модель `.gguf` в появившемся проводнике.
5. Выберите **Режим работы** (Чат, Кодер, Vision, Эмбеддинги, Реранкинг). От этого зависят дефолтные параметры.
6. Нажмите **«Настроить»**, чтобы выставить слои на GPU, контекст, включить Jinja, Reasoning, Draft или указать проектор (mmproj).
7. Нажмите **«Применить аргументы»**, а затем **«Создать конфиг»**.

## 3. Редактирование
Нажмите на иконку карандаша на карточке. Вы сможете изменить аргументы (например, поставить `--n-gpu-layers 99`, чтобы загрузить модель целиком в VRAM). Имя конфига менять нельзя.
*(Если сервер запущен, кнопка редактирования заблокирована — сначала нажмите «Стоп»).*
