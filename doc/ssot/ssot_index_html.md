# Паспорт файла: `index.html` + `style.css`

**Путь:** `llama_server/web_panel/templates/index.html` (и `static/style.css`)
**Статус:** production-ready

## 1. Назначение
Обеспечивает визуальный интерфейс (UI).
Стилистика: **Glassmorphism** (полупрозрачные панели, размытие фона `backdrop-filter`).
Каркас: адаптивный `CSS Grid`, который перестраивается в колонку на мобильных устройствах.

## 2. Ключевые элементы
- **Grid container** (`#instances-grid`): Сетка карточек.
- **Модальное окно создания/редактирования** (`#addModal`): Включает формы ввода, кнопки вызова проводника и кнопку «Настроить» (открывает скрытый блок с чекбоксами).
- **Модальное окно проводника** (`#explorerModal`): Вложенная модалка (z-index 2000), которая перекрывает основную форму, затемняя фон. Реализует навигацию по папкам.
