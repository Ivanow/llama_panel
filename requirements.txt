# ⚠️ НА САМОСТОЯТЕЛЬНУЮ УСТАНОВКУ ПОЛЬЗОВАТЕЛЕМ (НЕ в этом файле)
# Бэкенды ускорения для компиляции llama.cpp — с чем будет работать модель:
#
# 1) CPU (по умолчанию) — ничего дополнительно не требуется,
#    достаточно build-essential + cmake из списка выше.
#
# 2) NVIDIA CUDA — проприетарные пакеты NVIDIA ставятся отдельно:
#      - драйвер:  sudo apt install -y nvidia-driver-550 (или новее)
#      - toolkit:  https://developer.nvidia.com/cuda-downloads
#        (в PATH должен появиться `nvcc` — install.sh сам добавит
#         -DGGML_CUDA=ON при сборке, если найдет nvcc)
#
# 3) Vulkan — SDK/ICD от производителя GPU:
#      - sudo apt install -y libvulkan-dev vulkan-tools
#      - SDK: https://vulkan.lunarg.com (должен быть `glslc`)
#        сборка: cmake -B build -DGGML_VULKAN=ON
#
# 4) ROCm (AMD GPU, опционально):
#      - https://rocm.docs.amd.com (нужен hipcc)
#        сборка: cmake -B build -DGGML_HIP=ON
#
# Если ни один GPU-бэкенд не установлен, llama.cpp соберется на CPU.
# ============================================================
